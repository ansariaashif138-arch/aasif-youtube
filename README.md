# Aasif Youtube Android TV customization

This public repo provides the customized userscript used by the Aasif Youtube Android TV APK. The app loads the file at the repository root as `/.js` through jsDelivr.

## Changes

- Rebrands visible TizenTube labels to Aasif Youtube while retaining the settings entry and other settings rows.
- Removes only the Social Media Links row.
- Replaces the in-app settings icon with the supplied red YouTube play logo.
